The same engine,
a Pythonic API.

pip install millwright — a Pythonic pipeline over the same Rust engine, shipped on PyPI as an abi3 wheel built with maturin. Run it at Rust speed from a notebook.

Install & use

A pipeline, from Python.

pip install millwright
import millwright as mw

pipe = mw.Pipeline()
pipe.simple_imputer(strategy="median")
pipe.standard_scaler()
pipe.random_forest(n_trees=100, max_depth=8)   # or .linear_regression()

pipe.fit(rows, labels)          # list[list[float]], list[float]
preds = pipe.predict(rows)      # runs the Rust engine
metrics = pipe.evaluate(rows, labels)   # -> {"accuracy": …, "f1": …}
Roadmap. The API today is list-based; direct numpy / pandas interop (and a wider surface — search, more models) is the next step.

python is deliberately not part of full: pyo3's extension-module defers libpython symbols, so a plain cargo test can't link it. It is built and tested the way it ships — as a wheel. To build from source, from a virtualenv: maturin develop --features python.
